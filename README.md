# Portfolio for Alfabet

Portfolio of **Huub Ahsmann** — AI automation & IT engineering. Built with
Lovable (Vite + React + TanStack Start + Tailwind 4).

## What's inside

- **Single-page portfolio** (`src/routes/index.tsx`) — four selected projects
  with real code and screenshots, plus a grid of additional work.
- **Real scripts** (`src/python/`) — the actual Python tools behind the
  projects, displayed verbatim in the page's code blocks.
- **Real n8n workflow** (`src/n8n/`) — the chatbot workflow export, shown in
  the page as-is. Credentials are referenced via `$env.ODOO_*`; configure them
  in your n8n instance.

## Projects shown

1. Marketing expense sorter — sifted ~1,600 invoices into marketing spend buckets
2. Internal Assistant Chatbot — n8n + Gemini + Odoo, answering internal questions
3. Drupal QA checks & patches — thousands of pages checked and patched across migrations
4. Personal Hermes Agent setup — 24/7 autonomous assistant on a VPS

## Run locally

```sh
npm i
npm run dev
```
